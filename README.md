## 🌌 What is AniPulse?

AniPulse is an ultra-modern, cyberpunk-themed anime discovery engine built with pure HTML, CSS, and JavaScript. It connects directly to the **Jikan API v4** (unofficial MyAnimeList database) to give you real-time access to 10,000+ anime titles — no backend, no API keys, no signup required.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🌧️ **Matrix Rain** | Animated Japanese character rain canvas in background |
| ⚡ **Glitch Boot Screen** | Cyberpunk loading screen with progress bar |
| 🎴 **3D Card Tilt** | Cards tilt in 3D based on mouse movement |
| 🔴 **Live Particle System** | Interactive neon particles that react to mouse |
| 🔍 **Instant Search** | Debounced real-time anime search |
| 🎲 **Anime Roulette** | Random anime discovery in one click |
| 🎬 **Trailer Modal** | Watch YouTube trailers directly inside the app |
| ❤️ **Personal Vault** | Save favorites using localStorage |
| 📡 **Live API Data** | Real-time data from MyAnimeList via Jikan v4 |
| 📱 **Fully Responsive** | Works perfectly on all screen sizes |
